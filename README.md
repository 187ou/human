## 三、核心创新（答辩亮点）

### 3.1 行为因果挖掘（区别于关联统计）

普通 AI 只做「熬夜 + 任务完不成」关联统计，本 Agent 实现因果推理：
- 基于 DoWhy 框架构建用户生活有向无环因果图（DAG）
- 区分因果性与相关性：判断「是熬夜导致任务失败」还是「任务太难导致拖延」
- 输出因果链路：`睡眠时长 → 精力下降 → 任务拖延失败`

### 3.2 用户精力动态建模

建立用户每日精力值模型，四个维度综合打分：
- **睡眠质量** — 基于睡眠时长评估
- **昨日负荷** — 基于任务量和耗时
- **完成率** — 近期任务完成情况
- **专注度** — 有效专注时长占比

所有任务排布根据实时精力动态适配，而非固定时间表。

### 3.3 规则遗传演化（GA 算法）

规则不再是静态文本，具备自然迭代优胜劣汰能力：
- **交叉**：合并两条有效规则（高效时段 + 精力波动规则融合）
- **变异**：小幅调整规则参数（时段、阈值、权重）
- **筛选**：依据完成率、倦怠度、消费结余打分
- **淘汰**：劣质规则自动清除

### 3.4 GEPA 帕累托 Prompt 专属进化

ICLR2026 GEPA 算法实现，为每位用户生成独一无二的专属系统 Prompt：
- 基于用户轨迹生成多条 Prompt 变体
- 多目标帕累托评分：完成率 × 简洁度 × 共情适配 × 准确率
- 遗传操作：交叉 + 变异 + 选择
- 千人千 Prompt，不是千人一模型

### 3.5 生活稳态维持目标函数

演化不止追求效率最高，同时维持用户身心稳态：
- 连续高压学习 → 主动插入休息日、下调任务负荷
- 长期摆烂松弛 → 缓慢小幅提升任务量，避免骤增挫败
- 收支失衡 → 逐步优化消费结构，不生硬一刀切

### 3.6 三层弹性记忆架构

参考 AutoAgent 弹性内存编排机制：
- **瞬时记忆**：当日对话、临时日程（LangGraph 状态常驻）
- **情景记忆**：近 3 个月完整行为轨迹（ChromaDB 向量存储）
- **长期习惯记忆**：萃取固化规则、作息偏好（结构化数据表）

每日自动将短期记忆提炼压缩为长期经验，大幅削减 Token 消耗。

## 四、功能模块

### 4.1 五大业务 Agent

| Agent | 核心能力 |
|-------|----------|
| 时间规划 | 冲突检测、碎片时间挖掘、突发场景一键暂停/顺延、周期例外日程 |
| 消费记账 | 微信/支付宝账单导入、AI 自动打标（刚需/冲动/囤货）、弹性预算 |
| 物品收纳 | 层级存储位置（房屋→房间→柜体→格子）、双阶段临期预警、闲置识别 |
| 学习督导 | 知识点清单、错题记录、有效专注时长统计、动态难度调整 |
| 出行处理 | 开销预估、行李清单生成、日程联动、天气提醒 |

### 4.2 跨 Agent 场景联动

| 场景 | 联动链路 |
|------|----------|
| 短途出游 | 出行规划 → 清空周末日程 → 预留预算 → 行李清单 → 顺延学习 |
| 备考冲刺 | 上调学习任务 → 压缩娱乐日程 → 缩减娱乐预算 |
| 生病休养 | 暂停学习工作 → 调低饮食预算 → 延后全部待办 |

### 4.3 六大生活状态

日常 · 备考 · 出差 · 假期 · 生病 · 加班 — 状态切换时全模块自动适配。

## 六、快速开始

### 方式一：本地开发

```bash
# 1. 安装依赖
uv sync

# 2. 启动后端
uv run uvicorn app.main:app --host 127.0.0.1 --port 8001

# 3. 启动前端（另开终端）
cd frontend && npm install && npm run dev
```

浏览器打开 `http://localhost:5173`

### 方式二：Docker

```bash
docker compose up -d
```

## 八、请求示例

```bash
# 选择角色
curl -X POST http://localhost:8001/api/auth/select \
  -H "Content-Type: application/json" \
  -d '{"user_id": 1}'

# 添加日程
curl -X POST http://localhost:8001/api/schedules \
  -H "Authorization: Bearer $TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"title":"高数","start_time":"2026-08-15 09:00:00","end_time":"2026-08-15 10:00:00"}'

# 触发演化
curl -X POST http://localhost:8001/api/engine/nightly-evolution \
  -H "Authorization: Bearer $TOKEN"

# 切换场景
curl -X POST http://localhost:8001/api/fsm/switch-state \
  -H "Authorization: Bearer $TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"new_state":"exam"}'

# GEPA Prompt 进化
curl -X POST http://localhost:8001/api/gepa/evolve/study \
  -H "Authorization: Bearer $TOKEN"
```
